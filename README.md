# CER2-OLIVARESFERNANDO

-1
Clonar repositorio: https://github.com/ffernan2/CER2-OLIVARESFERNANDO.git

-2
Entrar a la carpeta: cd CER2-OLIVARESFERNANDO

-3
Instalar requirements.txt: -r requirements.txt

-4
Migrar base de datos: python manage.py migrate

-5
Ejecutar el servidor en la terminal: python manage.py runserver

Usuarios:

Existe 2 usuarios de prueba

Usuario con permisos de Admin:

Usuario:    pruebaUsuarioAdmin
Contraseña: contraseña123

Usuario sin permisos:

Usuario:    pruebaUsuario
Contraseña: contraseña123

El usuario con permisos de admin puede agregar y/o quitar usuarios,
añadir lugares, modificarlos y eliminarlos.

Mientras que el usuario sin permisos no puede acceder a los paneles de admin,
no puede agregar ni quitar o modificar lugares, usuarios o categorias, solo puede verlas.
