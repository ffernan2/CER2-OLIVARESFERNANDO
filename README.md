# CER2-OLIVARESFERNANDO

-1
Clonar repositorio: https://github.com/ffernan2/CER2-OLIVARESFERNANDO.git

-2
Entrar a la carpeta: cd CER2-OLIVARESFERNANDO

-3
Instalar requirements.txt: -r requirements.txt

-4
Migrar base de datos: python manage.py migrate

-5
Ejecutar el servidor en la terminal: python manage.py runserver

Tema usuarios:

-Para crear un super usuario se debe ir a django admin y agregarlo desde el panel
o en la terminal escrbir python manage.py createsuperuser y seguir los pasos

-Para crear un usuario editor se debera marcar los permisos para añadir y cambiar lugares pero que no sea de staff ni superusuario

-Y para crear un usuario editor se debe crear sin ningun permiso especial.
